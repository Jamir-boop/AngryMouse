# AngryMouse

![Icon](https://github.com/Jamir-boop/AngryMouse/raw/master/icon.png)

This is a very dumb application that implements OS X's shake to find mouse feature using WPF. This is a detached fork from the now abandoned Longi94/AngryMouse project. Go to [releases](https://github.com/Jamir-boop/AngryMouse/releases) to download the latest binary.
